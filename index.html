🤔 Codex CLI って何でち？

まずは「これが何なのか」から おべんきょうするでち！

Codex CLI（コデックス シーエルアイ）は、 OpenAI っていう会社が作った「おしゃべりできるプログラミングロボット」でち！

パソコンの「ターミナル」っていう まっくろいお部屋の中で動くでち。 ターミナルはパソコンに文字でお仕事を頼むための場所でち。

「このファイル読んで〜」「ここ直して〜」「このコマンド動かして〜」って おしゃべりするだけで、ぜ〜んぶやってくれるでち！

しかもオープンソース（中身が全部公開されてる）で、Rustっていう速い言語で作られてるから、サクサク動くでち！

📦 インストール（パソコンに入れる方法）でち

npm install -g @openai/codex brew install --cask codex

GitHub からバイナリ（実行ファイル）をダウンロードもできるでち

✨ できること一覧でち

Codex CLI にお願いできることを ぜんぶ並べたでち！

📖
ファイルを読む
パソコンの中のファイルを見てくれるでち！コードも設定ファイルもぜんぶ読めるでち。画像やスクリーンショットも見れるでち！
✏️
ファイルを書き換える
ファイルの中身を直してくれるでち！「ここをこう変えて」って言うだけで、ピンポイントで修正してくれるでち。
📝
ファイルを新しく作る
新しいファイルを作ってくれるでち！「index.htmlを作って」って言えば中身も全部書いてくれるでち。
💻
コマンド実行
パソコンに直接お仕事を頼んでくれるでち！npm install とか git push とか、ターミナルのコマンドを代わりにやってくれるでち。
🌐
ウェブ検索
インターネットでしらべものしてくれるでち！最新の情報やドキュメントを調べて教えてくれるでち。キャッシュ（保存した検索結果）も使えるでち！
🔍
コードを探す
プロジェクトの中から必要なコードを探してくれるでち！ファイル名でもコードの中身でも検索できるでち。
🌿
Git 操作
コードの履歴を管理するGit（じっと）を使えるでち！セーブしたり、前の状態に戻したり、みんなに見せたりできるでち。
🖼️
画像を見る
スクリーンショットやデザインの画像を見せると、それを理解してコードにしてくれるでち！目が見えるロボットでち！
🤖
マルチエージェント
むずかしいお仕事は、専門のロボットを何体も同時に呼んでくれるでち！みんなで手分けするから早いでち！（実験的機能でち）
🔌
MCP（外部ツール連携）
MCP っていう仕組みで、他のツールとつながれるでち！Codex 自身を MCP サーバーとして他のロボットに使わせることもできるでち。
💾
セッション再開
前にお話しした内容を覚えてて、途中から再開できるでち！ codex resume --last で前回の続きからでち。
📐
計画モード（Plan）
大きなお仕事の前に「こうやって進めるよ！」って計画を立ててくれるでち。/plan で切り替えられるでち。
☁️
Codex Cloud
クラウド（インターネット上）でも動くでち！大きなお仕事はクラウドに任せて、結果を codex apply でもらうでち。
🧩
IDE 連携
VS Code、Cursor、Windsurf などのエディタの中でも使えるでち！ターミナルじゃなくてもOKでち。

🛡️ 承認モードでち

Codex にどこまでお仕事を任せるか、3つのレベルから選べるでち！

🟢
Suggest（おうかがい）
ぜんぶ聞いてくれるモードでち。
ファイルを作る時も、直す時も、コマンドを動かす時も、ぜんぶ「いい？」って聞いてくれるでち。
初心者のばぶちゃんはこれがおすすめでち！
codex --approval-mode suggest
🟡
Auto-Edit（おまかせ編集）
ファイルの作成・編集は勝手にやるけど、コマンド実行だけは聞いてくれるモードでち。
ちょっと慣れてきたばぶちゃん向けでち。
codex --approval-mode auto-edit
🔴
Full-Auto（ぜんぶおまかせ）
ファイルもコマンドもぜんぶ勝手にやるモードでち。
⚠️ 危ないコマンドも勝手に動かしちゃうから注意でち！
信頼できる環境だけで使うでち。
codex --approval-mode full-auto

🏖️ サンドボックス（お砂場）って？
Codex が触れる範囲を制限する安全装置でち！
read-only：読むだけ ／ workspace-write：今のフォルダだけ書ける ／ danger-full-access：なんでもできる（危険）
ふだんは workspace-write で十分でち。

⌨️ ターミナルコマンド大全でち

パソコンのターミナルで打つコマンドでち！起動する時に使うやつでち。

🚀 codexAPI使う▼

Codex を起動するいちばん基本のコマンドでち！

ターミナルに codex って打つと、おしゃべり画面（TUI）が開くでち。ここでお話しながらお仕事をお願いするでち。

💡 使い方：codex だけでOK！プロンプト（お願い）を直接渡すこともできるでち → codex "このバグ直して"

よく使うオプション：

🔹 --model モデル名 → 使うAIの頭脳を変えるでち

🔹 --approval-mode suggest/auto-edit/full-auto → 承認モードを決めるでち

🔹 --image 画像のパス → 画像を一緒に渡せるでち

🔹 --path フォルダのパス → 作業するフォルダを指定するでち

🔹 --json → 結果をJSON（機械が読みやすい形）で出すでち

🔹 --provider プロバイダ名 → AIのプロバイダを変えるでち

🔹 --profile プロファイル名 → 設定のプロファイルを選ぶでち

🔹 --enable 機能名 → 実験的な機能をオンにするでち

🔹 --writable-root パス → 書き込みOKなフォルダを追加するでち

🔹 -c key=value → 設定を一時的に変えるでち

⚠️ 対話するたびに API（おはなし窓口）を使うので、お金がかかるでち。ChatGPTのプラン（Plus/Pro/Team等）に入ってれば含まれてるでち！
⚡ codex execAPI使う▼

おしゃべり画面を開かずに、一発でお仕事を頼むコマンドでち！

結果はターミナルにそのまま出てくるでち。スクリプトや自動化に便利でち！

💡 codex exec "テストを実行して結果を教えて"
エイリアス（別名）：codex e でもOKでち

パイプ（|）でプロンプトを渡すこともできるでち → echo "バグ直して" | codex exec

🔄 codex resumeAPI使う▼

前のおしゃべりの続きから再開するコマンドでち！

Codex はお話の記録を自動で保存してくれてるから、いつでも戻れるでち。

💡 codex resume --last → 最後のセッションの続きでち
codex resume セッションID → 特定のセッションでち
📥 codex apply無料▼

Codex Cloud（クラウド版）で作った変更を、自分のパソコンに取り込むコマンドでち！

クラウドでやったお仕事の結果（diff）をローカルに適用するでち。

💡 codex apply または codex a
☁️ codex cloud-tasks無料▼

Codex Cloud のタスク（お仕事）を一覧で見たり実行したりするでち！

おしゃべり画面を開かなくても、クラウドのお仕事を管理できるでち。

💡 codex cloud-tasks
🔑 codex login無料▼

Codex にログインするコマンドでち！

ブラウザが開いて ChatGPT アカウントでログインできるでち。APIキーでもログインできるでち。

💡 codex login → ブラウザでログイン
codex login --device-code → デバイスコードでログイン
codex login --with-api-key → APIキーでログイン
⚠️ APIキーを使う場合は、OpenAI のAPIの料金が別途かかるでち。ChatGPTアカウントでログインするのがおすすめでち！
📜 codex completion無料▼

ターミナルの補完スクリプトを作ってくれるでち！

Tab キーで codex のサブコマンドが自動補完されるようになるでち。

💡 codex completion zsh / codex completion bash / codex completion fish
🧪 codex features無料▼

実験的な機能のオン・オフを管理するコマンドでち！

💡 codex features list → 機能一覧を見るでち
codex features enable 機能名 → オンにするでち
codex features disable 機能名 → オフにするでち

主な機能フラグ：

🔹 shell → シェル（コマンド実行）ツール（デフォルトON）

🔹 unified_exec → 統合PTY実行ツール（ベータ）

🔹 bwrap_sandbox → Linuxサンドボックス（実験的）

🔹 apply_patch_freeform → フリーフォームパッチ（実験的）

🔹 apps → ChatGPT Apps連携（実験的）

💡 codex mcp-server

⚡ スラッシュコマンド大全でち

Codex の中で / を打つと使えるコマンドでち！おしゃべり中に設定を変えたりできるでち。

🧠 /modelモデルで料金変動▼

使うAIモデル（頭脳のレベル）を変えるでち！

GPT-5.3-Codex（標準）や GPT-5.3-Codex-Spark（軽量・高速）などに切り替えられるでち。推論レベル（どれだけ深く考えるか）も調整できるでち。

📐 /planAPI使う▼

計画モードに切り替えるでち！

「こうやって進めるよ！」って計画を立ててから実行してくれるから、大きなお仕事の時に安心でち。

💡 /plan → 計画モードに入るでち

画像も一緒に貼り付けられるでち。

※ /approvals でも同じことができるでち（古い名前でち）。

💡 /diff

💰 お金のおはなしでち

いちばん大事！お金がかかるところをしっかり理解するでち。

🍼 ばぶちゃんが知っておくべきこと

  • Codex CLI を使うには ChatGPT のプラン（Plus / Pro / Team / Edu / Enterprise）に入ってる必要があるでち
  • ChatGPT Plus は月額 $20（約3,000円）でち
  • プランに入ってれば Codex CLI の基本利用はプランに含まれてるでち
  • API キーで使う場合は別料金でち。使った分だけお金がかかるでち（従量課金）
  • /model で重いモデルに変えると、トークン消費が増える＝お金が増えるでち
  • ウェブ検索もトークンを使うでち
  • お金が心配な時は /status でトークン使用量をチェックするでち

🌟 お金をなるべく使わないコツでち
✅ ChatGPT のプランでログインするでち（APIキーより安定）
✅ 軽いモデル（Spark）を使うでち
✅ /compact でこまめに会話を圧縮するでち
✅ 必要ない時はウェブ検索を避けるでち
✅ Suggest モードで無駄な実行を防ぐでち
